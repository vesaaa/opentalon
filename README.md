# 园区停车数字孪生 Demo（Three.js）

独立的纯静态演示。Three.js 通过 CDN 加载，无需安装和构建。

## 运行

直接用浏览器打开 `index.html`，或在仓库根目录起一个静态服务：

```bash
python3 -m http.server 8080   # 然后访问 http://localhost:8080
```

## 功能

- 办公楼 + 地下两层停车场（B1 / B2，共 128 个车位）；东侧 3 条入口车道、西侧 3 条出口车道，共六个道闸
- 地面是绕楼逆时针的单向环路：东侧入场后北行，在北侧约 1 点钟方向下坡入库；出库后经北侧、西侧到出口。出入口之间有一间小餐厅
- 视角：左键拖拽旋转，右键或 Shift 拖拽平移，滚轮/双指缩放；可切换 全部 / 地面 / B1 / B2
- 贴图：玻璃幕墙、裙楼石材、铺装、沥青、草地等全部用 canvas 程序生成，不加载图片文件
- 画质三档：流畅（无显卡加速的电脑）/ 标准 / 高（实时阴影、天空反射、色调映射、凹凸贴图、雨天湿路面）；首次打开自动选择，帧率过低自动降档
- 环境：白天 / 夜晚，可叠加 晴 / 雨 / 雪 / 大雾
- 月卡车自动识别进出；临时车进场免停，出场停留缴费（15 分钟内免费，首小时 ¥10，之后每小时 ¥5，封顶 ¥50）
- 点击任意闸机查看当前车辆、停车时长和应付金额
- 充电桩：B1 / B2 背靠墙的两排车位各有一台（共 64 台），停入的车辆随机充电，指示灯显示空闲 / 充电中 / 已充满
- 点击任意车辆查看车牌、类型、车位、停车时长、当前计费和充电信息（功率、电量、已充电量、充电费）
- 异常场景：费用争议、已缴费未抬杆、欠费追缴（弹窗显示联盟停车场欠费汇总，详情可看本市 / 本省欠费分布示意图）。可在控制台手动触发，也可打开 Auto 按概率触发
- 异常时顶部出现红色告警，点击后镜头聚焦到对应出口，可「直接开闸放行」或「修改金额并重新缴费」

## 结构

| 文件 | 内容 |
| --- | --- |
| `js/scene.js` | 渲染器、相机控制、昼夜与天气、建筑/车库/道路、闸机与车辆模型 |
| `js/arrears.js` | 欠费追缴的演示数据与本市 / 本省示意地图 |
| `js/sim.js` | 行车路线、车辆状态机、闸机收费流程、异常场景 |
| `js/ui.js` | 控制台、统计、告警、闸机详情面板、主循环 |
| `css/style.css` | 界面样式 |
